# 📱 গিটহাব থেকে অ্যান্ড্রয়েড এপিকে (Android APK) রিলিজ নির্দেশিকা
## GitHub Actions Android APK Build & Release Guide

এই প্রজেক্টে সম্পূর্ণ অটোমেটেড **GitHub Actions CI/CD Pipeline** তৈরি করা হয়েছে। আপনি কোড গিটহাবে পুশ করলেই অথবা কোনো নতুন ভার্সন ট্যাগ করলেই স্বয়ংক্রিয়ভাবে অ্যান্ড্রয়েড এপিকে (`Universal-Video-Downloader-v1.0.0.apk`) তৈরি হবে এবং গিটহাব রিলিজ সেকশনে যুক্ত হয়ে যাবে।

---

### 🚀 ১. প্রথমবার গিটহাবে কোড আপলোড করার নিয়ম (Push to GitHub)

আপনার টার্মিনালে নিচের কমান্ডগুলো রান করুন:

```bash
# ১. গিট ইনিশিয়ালাইজ করুন (যদি পূর্বে না করা থাকে)
git init

# ২. সব ফাইল যুক্ত করুন
git add .

# ৩. কমিট করুন
git commit -m "feat: Add Android Capacitor configuration and GitHub Release CI/CD"

# ৪. মেইন ব্রাঞ্চ নির্বাচন করুন
git branch -M main

# ৫. আপনার গিটহাব রিপোজিটরির রিমোট লিঙ্ক যোগ করুন (আপনার ইউজারনেম ও রেপো নাম দিয়ে পরিবর্তন করুন)
git remote add origin https://github.com/<your-username>/<your-repo-name>.git

# ৬. গিটহাবে পুশ করুন
git push -u origin main
```

---

### 📦 ২. নতুন অ্যান্ড্রয়েড এপিকে রিলিজ তৈরির উপায় (Create APK Release)

#### পদ্ধতি ক: গিট ট্যাগ দিয়ে রিলিজ (সবচেয়ে সহজ ও জনপ্রিয় পদ্ধতি)
যেকোনো সময় নতুন ভার্সনের APK রিলিজ করতে টার্মিনালে শুধু ২টি কমান্ড দিন:

```bash
# নতুন ভার্সন ট্যাগ তৈরি করুন (যেমন v1.0.0, v1.0.1, v1.1.0)
git tag v1.0.0

# ট্যাগটি গিটহাবে পুশ করুন
git push origin v1.0.0
```
👉 এটি সাথে সাথে GitHub Actions চালু করে দেবে এবং অটোমেটিকভাবে:
1. কোড কম্পাইল করবে
2. ক্যাপাসিটর অ্যান্ড্রয়েড প্ল্যাটফর্ম সিঙ্ক করবে
3. গ্রেডল (Gradle) দিয়ে `.apk` ফাইল তৈরি করবে
4. **GitHub Releases** ট্যাবে `Universal-Video-Downloader-v1.0.0.apk` আপলোড করে রিলিজ প্রকাশ করবে!

---

#### পদ্ধতি খ: গিটহাব ওয়েবসাইট থেকে ১-ক্লিকে রিলিজ (Manual Trigger)
যদি টার্মিনাল ছাড়া সরাসরি ব্রাউজার থেকে বানাতে চান:
1. আপনার GitHub Repository-তে যান।
2. উপরের **"Actions"** ট্যাবে ক্লিক করুন।
3. বাম পাশের মেনু থেকে **"Build and Release Android APK"** সিলেক্ট করুন।
4. ডানপাশে **"Run workflow"** বাটনে ক্লিক করুন।
5. "Publish as GitHub Release" চেকবক্সে টিক দিন এবং ভার্সন লিখে **"Run workflow"** চাপুন।

---

### 📥 ৩. তৈরি হওয়া APK ফাইল ডাউনলোড করার নিয়ম

1. আপনার গিটহাব রিপোজিটরির ডানপাশে **Releases** সেকশনে যান (অথবা `https://github.com/<username>/<repo>/releases` লিঙ্কে যান)।
2. রিলিজের নিচে থাকা `Assets` ড্রপডাউনে ক্লিক করলেই দেখতে পাবেন:
   - **`Universal-Video-Downloader-v1.0.0.apk`**
3. ফাইলটিতে ক্লিক করে সরাসরি ফোনে ডাউনলোড করে ইনস্টল করে নিন!

---

### 📱 ৪. অ্যান্ড্রয়েড ফোনে ইনস্টল ও পারমিশন গাইড

1. ডাউনলোড হওয়া `.apk` ফাইলে ক্লিক করুন।
2. যদি ফোন ওয়ার্নিং দেখায়, তবে **"Settings"**-এ গিয়ে **"Allow from this source"** বা **"Install unknown apps"** অন করুন।
3. ইনস্টল সম্পন্ন হলে অ্যাপটি ওপেন করুন।
4. অ্যাপটি আপনার ফোনের মেমোরি/SD কার্ডে সরাসরি ফুল HD ভিডিও এবং MP3 অডিও সেভ করতে প্রস্তুত!
